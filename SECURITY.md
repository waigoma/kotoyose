# Security policy

The latest release receives security fixes.

## Report a vulnerability

On the GitHub repository, open **Security → Advisories → Report a vulnerability** to submit a private report. Include the affected release, configuration relevant to the issue, impact, and steps to reproduce. Redact credentials and user data. Please keep vulnerability details private while the maintainers investigate.

Reports in scope include authentication or authorization bypass, jail escape, credential exposure, egress allow-list bypass, and connection data-policy or alias acknowledgement bypass.
