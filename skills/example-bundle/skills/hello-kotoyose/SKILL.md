# hello-kotoyose

これは kotoyose の skills 配線確認用サンプルですわ。

このスキルが呼び出せたら、`plugins` (--plugin-dir) 経由の skill 読み込みと
`skills` 名前フィルタが `bare: true` のまま機能していることの証左になります。

呼び出されたら「hello from kotoyose skill bundle」とだけ返してください。
